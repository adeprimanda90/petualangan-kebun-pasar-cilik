# 🐰🍎 Petualangan Kebun & Pasar Cilik (PWA Offline)

Aplikasi game edukasi anak berbasis web (Progressive Web App / PWA) dalam **Bahasa Indonesia** yang dirancang khusus agar ringan (**60 FPS**), ramah sentuhan anak, dan dapat diinstal serta dimainkan **100% offline** di perangkat Android (termasuk optimasi khusus untuk **Samsung Galaxy A8 2018** rasio 18.5:9).

## ✨ Fitur Utama
- **Mode A — Kebun Ceria (Usia TK / 3–5 Tahun):**
  - *Mengenal Warna:* Memasukkan 3 buah/sayur berbeda dengan warna yang sama ke dalam keranjang (mendukung *Tap-to-move* maupun *Drag-and-Drop*).
  - *Berhitung Dasar (1–5):* Memetik buah sambil dihitung lantang dengan suara Bahasa Indonesia (*"Satu... Dua... Tiga..."*).
  - *Huruf Awal (Fonik Abjad Indonesia):* Mengenal huruf awal nama buah dan sayur.
- **Mode B — Pasar Cilik (Usia SD / 6–7 Tahun):**
  - *Kereta Suku Kata:* Menyusun kata **2, 3, hingga 4 suku kata** dari minimal **6 pilihan gelembung suku kata**.
  - *Kasir Cilik (5 Koin):* Menjumlahkan kombinasi 2 atau 3 koin dari pilihan koin **1, 2, 3, 4, dan 5**.
  - *Kasir Cilik (Penjumlahan & Pengurangan 1–15):* Berhitung belanjaan buah dan sayur.
- **60 Varian Buah & Sayur + Ilustrasi Vector SVG Akurat:** Termasuk buah tropis Indonesia seperti Manggis, Nanas Madu, Durian, Rambutan, Salak, Sawo, Delima, Buah Naga, Jambu Air, Jambu Biji, Belimbing, Nangka, Cempedak, Duku, Sirsak, Srikaya, Kedondong, Pepaya, dll.
- **100 Koleksi Stiker Bersuara Bahasa Indonesia:** Setiap menyelesaikan 1 set (10 soal), anak mendapat +1 Bintang ⭐, hujan konfeti, dan membuka 1 stiker baru.
